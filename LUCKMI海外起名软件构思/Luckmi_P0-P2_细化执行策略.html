01

整体策略与市场定位

◈

市场空白切入点

海外八字起名市场被两类玩家占据：纯中文命理站（中国人用）、纯英文星座/塔罗站（西方人用）。中英双语的专业八字起名是稀缺品类，海外华人和对东方玄学感兴趣的西方人是核心双客群。

◇

产品形态决策

优先网页端 + PWA，跳过原生 App。原因：八字起名低频场景（用一次就走）、网页获客成本远低于 App Store、海外用户习惯 Web 工具、PWA 可覆盖 80% 的 App 体验。

◆

商业化节奏

P0 单次付费验证（$2.99 首单）→ P1 会员订阅（$9.99/月）→ P2 高客单报告（$49/$169）+ 专家咨询（$98/30min）。从轻到重，逐步抬升客单价和 LTV。

◉

增长策略

SEO 内容矩阵为核心（100+ 名字详情页 + 生肖页 + 博客），配合 TikTok/Instagram 短视频引流，邮件订阅做留存。不靠广告投放，靠内容复利增长。

02

P0 阶段：MVP 核心链路

P0

最小可用产品 · 核心验证

⏱ 约 2 天 · 开发中
目标：跑通「八字输入 → AI 排盘 → 起名推荐 → 支付 → 交付结果」完整链路，验证用户付费意愿。
核心指标：支付转化率 ≥ 3%，首单成本 < $1.5
2.1 前端页面（Day 1）
  • 落地页 / 首页：品牌介绍 + 功能价值 + 定价 + 立即起名 CTA 前端
  • 八字输入表单：出生年月日时 + 性别 + 出生地区（时区自动映射） 前端
  • 排盘结果页：天干地支 / 五行统计 / 十神分析可视化 前端
  • 名字推荐页：3-5 个中英文名字 + 含义 + 五行评分 前端
  • 响应式适配：桌面 + 移动端（海外 60%+ 移动流量） 前端
  • 全局 i18n 架构：中/英双语切换组件 + 语言包 前端
2.2 AI 核心能力（Day 1-2）
  • 八字排盘工作流：输入生日→计算天干地支→五行分析→十神判定 AI工作流必做
  • 起名生成工作流：基于八字五行喜忌→生成中英文名字→给出评分和解释 AI工作流必做
  • Coze API 对接：前端调用工作流，流式返回结果 后端
2.3 用户系统（Day 2）
  • 邮箱注册/登录：Supabase Auth 接入 后端
  • 起名历史记录：用户保存/查看过往起名结果 后端
  • 用户中心页：基础资料 + 历史记录列表 前端
2.4 支付接入（Day 2，测试模式）
  • PingPong 跨境支付接入（测试环境） 支付
  • Quick Name SKU：首单 $2.99 / 复购 $4.99 支付
  • 支付成功回调 → 解锁完整名字列表 后端
  • 订单表设计：用户ID / 订单号 / 金额 / 状态 / 创建时间 后端
📦 P0 交付物清单
模块交付物验收标准
前端5 个核心页面 + 双语切换可在手机和桌面正常浏览，语言切换无遗漏
AI2 条工作流（排盘+起名）输入生日后 30s 内返回排盘和 3 个名字
用户注册登录 + 历史记录邮箱可注册登录，起名结果自动保存

  • 会员权益页：对比展示各等级权益差异 前端

3.2 SEO 内容矩阵（Day 2-3）
  • 100 个名字详情页：每个名字单独页面（含义+五行+适合八字+名人案例） 内容核心
  • 5 个生肖专题页：2025 蛇年起名 / 龙年 / 马年 / 羊年 / 猴年 内容
  • 博客首篇：「How BaZi Naming Works」「Chinese Name Guide」 内容
  • 技术 SEO：sitemap.xml / robots.txt / 结构化数据 / Open Graph 前端
  • URL 结构优化：/names/xxx /zodiac/snake /blog/article-slug 前端
3.3 高客单 SKU 上线（Day 4-5）
  • BaZi Name Report（$49）：深度八字分析 + 20 个精选名字 + PDF 报告 AI工作流
  • 年度运势报告（$169）：年度大运流年分析 + 月度运势 + PDF AI工作流
  • 专家咨询入口（$98/30min）：预约页面 + 日历对接 + 视频会议链接 运营
  • PDF 报告生成：服务端生成精美 PDF 并发送邮件 后端

  • 邮件订阅系统：起名结果页引导订阅 + 每日运势邮件 内容
  • 分享裂变：起名结果可分享到社交平台，带来新用户 前端

05

中英双语全局架构

确认：MVP 阶段全站中英双语。 海外八字起名的核心客群是两类人——海外华人和对东方玄学感兴趣的西方人。双语是标配，不是加分项。

实现方式：React i18next / Vue i18n 架构，语言包独立管理，支持浏览器语言自动检测 + 手动切换。所有页面、邮件、PDF 报告均双语。

  • 会员定价页✓ 双语

系统层（全部双语）
