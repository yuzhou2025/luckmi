03 技术架构与开发方案

渐进式技术路线：网页 → PWA → TWA → Capacitor 原生壳。同一套代码渐进升级，避免重复开发。

  • UI 组件 Element Plus / 自研
  • 状态管理 Pinia
  • 国际化 Vue I18n
  • PWA Vite PWA Plugin

后端

  • 语言 Node.js / Python
  • 框架 FastAPI / Express

  • P0 网页 纯 Web + PWA

基础设施

  • 服务器 AWS / Vercel
  • CDN Cloudflare
  • 邮件 Resend / SendGrid
  • 监控 Sentry + GA4
  • 支付 Stripe / PingPong

C. 报告与咨询 月度报告、年度报告、运势建议、专家咨询 P2 ~3周 AI 长文生成 + PDF 导出 + 预约系统
D. 免费工具 万年历、吉日查询、解梦 P0 MVP ~1周 黄历算法 + 周公解梦库
🧠 八字算法核心注意事项

八字排盘是产品的"地基"，算法准确性直接决定专业度和口碑。关键要点：

  • 真太阳时：必须根据用户出生地经纬度换算真太阳时，不能直接用北京时间排盘，这是专业度的分水岭
  • 节气换月：月柱以节气（立春/惊蛰/清明...）为准，不是农历月份
  • 五行旺衰：不要用简单的"计数法"判断五行强弱，要用月令 + 通根 + 生助综合判断
  • 喜用神：这是起名的核心依据，算法复杂度最高，建议 MVP 阶段引入人工校验

iOS IAP 策略

⚠️ Apple 30% 抽成是硬成本，必须策略应对

App Store 规定：数字内容和服务必须走 IAP（应用内购买），抽成 30%（第二年小企业 15%）。起名类单次购买可以引导到网页端支付（省 30%），但会员订阅必须走 IAP。

06 海外推广与获客策略

三条核心获客渠道，按 ROI 排序：SEO 内容 > 社交媒体 > 付费投放。MVP 阶段聚焦 SEO 和内容，有收入后再投放放大。

渠道一：SEO 内容营销（ROI 最高）

🔑 核心策略：用 1000 个内容页面，吃下长尾搜索流量

海外用户搜"chinese name meaning"、"bazi calculator"、"year of dragon personality"等长尾关键词，每个页面都是一个获客入口。1000 个页面 = 1000 个入口，且是一次生产、长期受益。

07 合规与风控

海外做命理类产品，合规是生命线。App Store 审核、隐私法规、支付风控，每一项都可能让产品下架。

🛡️ App Store 审核红线

  • 避免 "destiny"、"fortune telling"、"算命" 等敏感词
  • 用 "personal insight"、"self-reflection"、"cultural guide" 等中性表达
  • 必须标注 "For entertainment purposes only"
  • 不能做确定性命运断言（"你一定会发财"是红线）
  • 不能涉及医疗、投资、法律建议
  • 准备好被拒 1-2 次，调整措辞后重新提交

🔒 隐私合规

  • GDPR（欧盟）：用户可申请数据导出和删除
  • CCPA（加州）：加州用户有数据知情权
  • 出生信息（生辰八字）属于敏感个人信息，加密存储
  • 隐私政策必须明确说明数据用途
  • 邮箱订阅必须有退订选项
  • AI 生成内容必须标注 "AI-generated"

支付风控

⚠️ 命理类产品是高风险商户，支付渠道可能随时冻结

Stripe、PayPal 对 "占卜/命理" 类商户有风控规则，高拒付率或投诉会导致账户冻结。必须提前做好风控措施。

  • 清晰的退款政策，页面显眼位置展示
  • 产品描述不夸大效果，避免"必发财""必转运"等承诺性语言
  • 监控拒付率，保持在 0.5% 以下
  • 准备备用支付渠道（PingPong + PayPal + Stripe 至少两条腿走路）
  • 用户购买前明确确认"数字产品一经交付不退款"，但保留人性化例外通道
  • 保留所有交易记录和沟通记录，应对争议仲裁
