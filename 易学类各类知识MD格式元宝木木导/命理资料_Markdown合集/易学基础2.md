# 七杀封印

# 神话世界，道门封印元神，削三花五气，剥神成凡，或封凡人之行尸走肉，此封印也。子平中，财官印食杀伤枭刃，正格娇贵，造化稀少，六正格之一，印为吉，聚气成格谓印格，吉神需佑，勿刑冲克破穿合绝生之吉神，印畏财冲、畏刑克、畏穿破。印格尤畏财冲破，比劫护印，七杀生印，印旺克食伤，断去财源，无财滋身，七杀为忌必封其印。

# 七杀逢印泄之，印逢比劫泄之，杀印、印比、财官、官印，强生弱，弱不得生，强封弱气也。以甲乙为例，水生木，水盛而木无根则旺水浮木，印水生木而木不得生，水盛木漂，水木反克，冬生木而无火，寒水冻木，此金强生寒水，金水寒冰封印木象，七杀逢印失时即封印，寒水生木而冻木，七杀封印而印封身。水木清华，水生木月食伤相泄，冬春之初反喜火暖，喜见丙丁。以丙丁为例，木生火，水为七杀，春木生火，运行北水，寒水生春木，木旺火弱，火反不能生，需庚辛劈木引火，寒水春木旺而火反熄，或以金劈木或引土培根。

# 七杀封印，七杀旺而身无根无以帮扶，七杀封印进而封身。杀格身强逢印运，印化杀为而封身，印格逢杀运，杀旺印旺元辰弱，七杀生之。七杀凶神，印为吉神，杀盛印弱不足化印生身，杀弱印盛不足显威权。杀强印旺方得杀印相生，印化杀而为生身之用，一杀一印互为相用，杀强印弱，杀以封印。官印相济，文治之象，官杀混杂，合杀留官为上。有杀方论杀，无杀方论用，七杀克身，命之第一性。官杀为十神之首，杀配印为首，或食制杀或刃驾杀，杀克身即封身，封印封身，以元辰抗杀无力则封之。天地造化，以克杀封命，肃封万物，冬藏春萌，物命之贵贱，以祸克杀考命之福缘深浅。印以问福，食以问寿，官以问禄，无福无以抵祸，无印无以化杀，杀化印而生身，建禄之旺抗杀，发用印喜身弱也。

# 观象以理，乾造六亲中，杀为子、印为母，无仇不成父子，无冤不成夫妻。子为杀，官为女，官杀克身，身克妻，妻财子禄，财印相冲，妻与母则相冲相克，或以子女通之。杀生印、印克伤，食伤配印，印配食伤，择其格调配之，贵贱不同，印重为枭，枭夺食而元辰无寿。吉神顺用，勿为所缺，造化极少，凶神逆用，无惧刑冲克害穿破绝，以凶神佑吉神或喜，观象吉凶各执其变，吉神造化四宫之变，凶神多凶事，其象贫贱寒残各自造化，吉者吉而凶者凶，星宫同参喜忌分呈，运现应期，故各自吉凶观命之一生造化，自执八九载以应命限。象理之差，观似是而非，论之用之大异，用象用理，以象代理，以宫定星，七杀凶神，观宫位所指喜忌分辨。例，乾造之七杀为子，星吉宫凶，其子能力非凡却处境艰危，逢险处事则愈强愈凶，其象吉冲破刑穿过之，落于年月则早，迟于日时则晚，杀在时宫，晚年归宿因子而寒。观象以理，望理成象，宫藏杀则六亲星处境寒微，星坐杀则身多凶。七杀为凶神之首，以七杀论命，其命兹艰，逢七杀必观印、观刃、观食，以印化七杀，七杀为我所用，以刃驾杀，身旺驭杀如虎添翼，以食制杀，以食强杀强而艺高胆大。

# 财官印食吉神成格，娇贵异常，大忌刑冲克害破绝穿，喜生合会助，印格喜杀，财格喜官，食喜劫比，杀格化印。印绶成格而日元弱喜生，空亡病死绝胎之位，或以微根为植，秉赋天成，喜杀助印，杀印生而刃助根，食伤泄之为忌， 杀无刃不显，刃无杀不威，杀印兵谋权变，文武兼之。吉神成象四平八稳于太平世青云直上，凶神成象则异路旁门诡诈善变处险而动，进退自如之变，通达权变，治世之能，乱世之枭，杀刃而显。文治武功取格观象，以杀印、财伤、官枭、食劫观之，无杀无威，无刃无能，无印无谋，无伤无奇，无食无福。兵谋善伐或以杀印相济，权谋多能或刃印通变，财官成象或富贵有常。杀重印浮，身弱喜助，运助财冲，以财生杀，破财免灾。杀印之功名，财食之利禄，尤辨之气象也！

# 官之贵，杀之逆，印之宅，财滋命，刃强身，枭夺寿，吉凶十神各异存之，杀逆为喜以化印，琴棋书画必伤配印，吉凶喜忌不可独论，唯杀之旺，命之劫数。七杀绕命，印化以用，七杀阻路逢杀封印，善能之事却寒束身，精兵善谋无福可享，空劳其身，封印之杀其劫压运，肃杀寒冬当以宅藏身，冬去春来，乘运而发。大福而大贵，大贵而大灾，早发早衰，寒削盛名，气运以先抑后扬而能大器免成，此以先天立命也！

# 两线官杀

# 天地万物，克为第一，十神以官杀为首，官为文治、杀为武功、官杀并举、印与教化，杀伤劫刃战祸分争不断，命运福祸寿夭尽在于此。两线官杀以官杀为用，以宫位为主，内冲克刑，外官杀运，喜而逢克成器，忌而官杀剥身，小人遭刑受鞭笞，君子不刑不发，刑克内外则命格内外交战，年时两线、干支内外交战。命格元辰面对内外绞杀环境或进或退无济于事，流年大运一旦引发冲克刑合，应期立现，逢刑必虚，逢杀必化，逢克必刃，财旺生杀而散财去杀，刑冲必断刑，三刑逢之远离三刑之属相之，引杀去财，引相去刑，引时去冲，近贵人必远小人，近小人必远贵人。

# 官杀为喜必得贵人，官杀为忌必近小人祸事，远近疏离皆决于喜忌，分喜忌以定官杀，福祸自定。刑冲，先刑后冲，冲而引刑，刑克亦为喜忌，喜刑而刑君子必发，忌刑而刑人受鞭笞，一刑一笞，喜忌而用之，年月日时各有不同。问财必起官杀，食伤生财，财引官杀，刃杀齐备，身旺者财官必弱，身弱者官杀必强，命弱者克耗多，命硬生扶多，元辰弱喜印比，元辰强喜官杀，财杀旺克，日元无力担财，必立起祸，少青中老时期，因各喜忌而强弱。命杀与运杀大异，命格带杀，若无制化则祸事连连，内结压力重重，克官杀力命中自来，环境险恶与生俱来，左突右冲，年日月时，环境即时空见杀。时空见杀，时空旋转盛衰，克杀越来见旺，杀境重重，日元有助则化杀制杀驭杀为用，日元若无助将遍地杀境无所遁藏。杀境分内外二境旋转变化，或时空克束、环境杀力，或因财而起，少贫寒青无依中无伴老无居，财杀重重，困顿折身，凶神齐聚，未见吉神，时空现重重官鬼，难得其力，两线官鬼内外杀克，以虚避实，以实转虚，化克官鬼之克。官重化杀，财重生杀，双杀临身，财官为十神之标尺，命格所向，杀来抵身而来，元辰必以印刃食佑之，方可脱。

# 余以为时空化杀，环境迅急旋转或由盛转衰，或由衰转盛，有形无形之克。以官杀为喜化官杀为用，财官分置，身弱以财官为忌，杀为印化，财旺克印，印比生身，食伤生财，元辰所克为财，先财后印受其荣，先印后财反受辱，财印相克，通之以官杀为介。十神不见禄，禄官财宅而禄为首，人之所享消深浅决于禄身，无禄身无以承财官之养，无以承受印食之福，官杀愈强则禄身愈旺，方可消受人间利禄功名。禄身根基旺盛，财官愈盛愈令人发福，官为禄食主寿印主福，官食财吉神越喜身旺，唯印喜身弱，以宅化杀则印可生禄以为用，印禄相见妙不可言。岁禄建禄坐禄归禄，杀重克来而禄根深厚，或以印之或以刃驾之或以食制之，克杀望禄，旺禄必食，食禄旺以抗杀临，以食抵杀，杀不足克之。大运透杀，外杀应期，其运艰难险恶，环境埋杀，元辰须借力化杀，以应期六亲，逆杀顺官，逆用凶神，顺用吉神。命格劫比抗之，外杀于运数，环杀明暗交集， 以杀力压劫比，杀刃凶神并用，命格尤喜环境险恶为用之，逆用凶神杀伤劫刃，时空克力杀伐并举杀刃伤，凶神令环境险恶，化险为夷。

# 命数运数，杀不离印，印不离杀，财杀一党，印比一党，财生杀化印生比，财格喜官克比夺，杀格不喜官混，印格喜官杀相生，比劫建禄格喜官杀克。杀印结运，以比抗杀，财不得数，印格畏财伤喜比劫护印，两线见杀需印化以护，运数各行其运或四。财格行官杀运，财生杀克身，以杀结祸，杀格行财运，因财引杀而来，取象财杀六亲，一财一杀，财杀交互而来，用神印为首刃次之食制三，以食伤泄身克耗制杀，食无力杀无制，印化强身抵杀。左右难取为用，女或以禄取财即以身体换钱，禄为克者财，克为禄之杀，一禄奉多杀，杀多禄折，官杀为克，凡克即取官杀，被克为财，官杀旺克一切，一切皆为财，万物为天地之财。造化异于克与被克之间，克重者命薄，官杀旺者必弱，财杀旺者祸必多，向财问杀，财杀结党，克身之象。富贵必是财官旺，身健必禄刃强，欲强必食伤旺，印比结党好文，逆行运数则阴男阳女，若贪财取物者，当以食伤为财源，食伤泄身，财官耗身，官杀克身，元辰旺衰可否泄之或耗之或助之。命格身弱命硬劫刃印比助身，官杀拦路化之驭之，食伤泄刃比，印克食伤而生日元，官杀束克以成气象，食伤泄生财官，一气流通而逢运数而腾空。余以为命数运数一体而流，数化干支而取象，知人世福祸之变。

# 午月辛金取用

# 辛金，同样五行属金，主义，但跟庚金比，辛金是阴性的金，少了一些刚烈，多了一些秀气，所以辛金也叫秀金，类像上为金银珠宝等细软之金。

# 辛金如金银珠宝，代表着一切体面的、具有装饰性的美好事物。所以，在社会生活中辛金日主多是得体而优雅的人，与之交流，常有如沐春风之感；辛金可以被锻造和塑造成各种形态，甚至拉伸成比头发还要细的金丝，可见辛金有着极强的可塑性和韧劲儿，所以，多数辛金日主表面给人柔和之感，但如果你深入接触了解就会发现他们的内心是相当坚韧有弹性的人。一些精美的珠宝表面，像镜子一样可以映射出周围的事物，如同辛金命主的内心，不声不语，但是心如明镜，把一切都收藏在眼底，辛金心思细腻，洞察力一流，身边大小事很难瞒得住他们的眼睛，只是说与不说而已。

# 《滴天髓》上有诗云：辛金软弱，温润而清，畏土之叠，乐水之盈。

# 能扶社稷，能救生灵，热则喜母，寒则喜丁。

# 辛金为贵金，自然生存条件就要苛刻一些，土是生金的，代表保护和呵护，但是土太多，又会把辛金埋没，所以辛金的土不能多，去除杂质，最好的办法就是大浪淘沙，所以辛金的第一先天气数位是壬水，谓之乐水之盈，但是这个水也不能太大，否则水多金沉，水多的时候就需要戊土治水来保持平衡。辛金也代表首饰之金，晶莹剔透，美丽玲珑，但是更需要保养。辛金是克甲木的，但是甲木能生丙火，丙火合辛金，这样就能化解甲木，此谓之能扶社稷，如辛金为女性，虽然矜贵，但是也主柔弱，没有男性的刚强，但是如果能嫁个好丈夫，如丙火，也照样能富贵。生在夏天，火旺太过，必须用土泄火气来生金，生在冬天水旺太过，必须，所以喜火暖身。如辛金为女性，夏天如小孩，需要父母的照顾给予帮助，大人的时候就要看丈夫，才能得到首饰打扮。所以夏天喜土印，冬天喜火官。

# 辛金虽然没有庚金那样强劲的肃杀之气，但是也具备金属性的阴冷气质，只是辛金严肃、冷峻的气场没有庚金外显，辛金更像是尖刀、银针，平时语言输出不多，说话比较收敛，一旦输出呛人就是一针见血，锐利，而且十分精准的刀刀戳人短处，简直是互怼小能手，他们很擅长带刺的嘲讽，食伤为辛金的人更加体现出言语的犀利。

# 辛金还有个特殊的天赋——第六感超强，辛金清润可观，性能通灵，在中国传统观念中，贴身佩戴的金器玉器都是有灵性的，辛金日主命局中有己土帮扶的时候（己土为辛金的偏印），容易与易学结缘，天赋极高，比如曾仕强教授就是辛金日主。

# 辛金的万物类像：辛象在天为月、在地为金玉、珠宝、玉器、钻石、金饰品、晶体、乐器、针、剪刀、笔、钱币、金融、医药、精加工、法律；于人体为肺、呼吸道、喉咙、鼻腔、耳朵、筋 骨、小骨骼；于人性为通达、柔润、灵动、好面子；其形为“致密”。

# 辛金出生的命主日子上有六种组合：【辛丑日】、【辛卯日】、【辛巳日】、【辛未日】、【辛酉日】、【辛亥日】：

# 【辛丑日】，又名【白玉生辉日】，土生金旺，坐库通根，坐下有偏印、 比肩、食神，主人灵秀，女命身材好，秀气，守家。

# 古诗云此日：“白玉生辉金门客，高山得贵子为墨。身入平川多愁叹，干弋影里勋业垂。”

# 【辛卯日】，又名【凤阙早步日】坐偏财，经济能力不错。男命英俊， 女命漂亮，很容易招男人喜欢，容易风流。

# 古诗云此日：“高山起程水流长，边塞迢迢雪满霜。佛山玉女岂有情，雪山日照花海棠。”

# 【辛巳日】，又名【金马登殿日】，【A级好日子】，自坐正官、正印、劫财，辛金柔弱，有正印生身，劫财帮助，由弱转旺，易有官贵，容易成功，女命利于婚姻。

# 古诗云此日：“金马临官号嘶风，玉堂拜相翰苑名。最喜高山水环绕，骄阳日出漫销魂。”

# 【辛未日】，又名【冰河解冻日】，土生金，无水则燥。坐下偏财、偏印、七杀，有小贵，女命辛未爱情专一，夺夫权，守家。

# 古诗云此日：“身入西国佛香地，漫歌轻舞管弦醉。玉女传送风流人，高山日出彩画新。”

# 【辛酉日】，又名【凤卧金山日】，干支一气，坐禄通根，得助，立于不败之地，聪明有文才，有能力。男女皆有不利婚姻之象。

# 古诗云此日：“禄马贵人世少有，凤卧金山将帅候。日出朝阳横天行，月圆金门寻石榴。”

# 【辛亥日】，又名【虎行天门日】，干支相生，金水相连，文才好，生性风流，女命坐下伤官旺不利夫， 男命可得妻财，或漂亮之妻。自带壬水甲木。带【孤鸾煞】女命不利婚姻。

# 古诗云此日：“一去天门遥遥远，长亭驿路关山寒。倒骑毛驴东行去，高山丽日花团团。”

# 月令为七杀的取用

# 午月丁火司令，辛金是最怕丁火的。

# 因为丁为熔炉，辛金就算有根，也承受不住丁火的煅烧，特别是午火见到甲木的时候。

# 甲午月或者寅年午月都很容易构成财生七杀无制，如果出现这种情况，就算日坐酉金或年见申金，都会被午火所伤。

# 根气受损的结果就是劳碌与伤痛，财生七杀为忌的组合是非常喜欢冒风险的。

# 特别是财很弱七杀很旺或者是一个财去生多个官杀的情况。

# 才代表我们的自有资金，官杀代表着事业的规模或者投资的标底物。

# 财弱七杀旺，就是手上只有一点钱，却撬动了远大于自有资金的规模，资金是常年处于紧张状态的。

# 而一个财去生多个官杀呢，就是用手上的一份钱去搞了多份的事业，妄想遍地开花，常年是十个锅九个盖，拆东墙补西墙，这两种组合的最终结果都是资金链断裂而失败。

# 所以午月的辛金是最怕有甲木来生午火的，不但在事业上跌宕起伏，还会在情感上踩大坑。

# 因为午火不但是花朵，还是七杀，而且有甲木来护着午火，就算有食伤也是无法制七杀的。

# 要先有庚金去治甲木。无庚，辛不能替代，因为辛金克不动甲木。

# 例如，庚寅年或甲午月，年或时见庚辰，然后日支还要有制化午火的用神，见亥水为制，见丑土为化。

# 未土不行，未为燥土，若大运流年见巳火，会组成巳午未三会火局来融化辛金。

# 所以财生七杀为忌的组合，一定要财杀同时被制才算有制。

# 若是原局没制化，就一定要记住，安守本分，素昧而行。

# 午月的辛金，是需要制化兼施的。

# 先有壬癸水来制七杀，再有己土来化七杀，单见水来制火，辛金又过于柔弱，不堪克泄。

# 单见己土无水，又土燥不生金，反而脆金，但壬己同用，又不能相战，相战则困水，只有隔柱而用为佳。

# 壬癸水并用，又不喜同透，同透则思虑不专。

# 壬透癸藏是最好的，癸藏就是地支见子水，丑土或者辰土。有些人一见到冲就很紧张，其实冲也有好的，忌神喜冲，吉神忌冲。

# 倘若月令为正官，就不能被冲，正官为稳定，冲则破。但七杀就不怕，七杀本就为武职，冲只是动中求成而已。而且七杀有制总比无制的好。

# 不过子为帝坐，午为端门，子午冲是很容易惹是生非的。如此组合，要多修心养性，注意祸从口出。

# 冲还有冲旺、冲凶、冲动、冲开、冲出、冲去、冲破几种情况，这个以后单独来讲。
