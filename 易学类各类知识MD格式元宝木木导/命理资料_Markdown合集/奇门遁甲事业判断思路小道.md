# 奇门遁甲事业判断思路小道

奇门遁甲事业判断思路

第一步  审题

审题-已知条件，核心问题，组织判断逻辑。

1、职业选择类：继续现在的工作还是换一个工作?→ 已知条件为现有岗位和变动意愿，核心问题是比较稳定性与发展性

2、求职预测类：什么时候能找到工作?→ 已知条件为失业状态，核心问题是时间节点判断

3.机会决策类："两个offer如何选" → 需分析各选项的有利因素和发展前景

第二步  找用神

纲领用神-开门为事业，日干为问测人，时干为事业概述。（下一个工作为开门地盘干，转盘天盘干时所在宫）。

太岁（年干）为大领导，值符直接领导，月干平级同事，时干下属，管理层为值使门

专用用神-杜门为武职/技术，景门为文职/策划，乙奇为设计/艺术。

当有二个用神代表某人时（如年命、时干或日干），通常时干（日干）用神为短期状态近期现状，年命为长期状态。

用神联系-用神很多要分清组合关系，区别用神所描述的面，否则容易出现很多矛盾点，导致无法下结论。

矛盾处理：

当开门生日干，但时干克日干时，表示岗位适配但发展不利；

景门生日干而杜门克日干时，说明文职方向更具优势；

现代扩展：电子设备对应丁奇（传统为灯火，现代可指手机/电脑）

网约车司机取伤门（动态性质），大车司机取庚（刚硬特性）

实践要点：建立用神优先级：先纲领后专用，保持概念核心不变（如丁奇始终代表"发光发热"特性），结合现代职业特征灵活取用

第三步 定趋势

核心方法:

1、以年命或日干的十二长生状态判断求测人的趋势是向上或向下；

2、以开门宫天干的十二长生状态判断工作或行业的趋势是向上还是向下。

阶段划分:

上升阶段: 从长生到帝旺（长生→沐浴→冠带→临官→帝旺）

下降阶段: 从衰到养（衰→病→死→墓→绝→胎→养）

状态解读:

长生位: 新兴行业/刚入职状态    沐浴位: 对现状产生新想法    冠带位: 获得职位/成就           临官位: 获得稳定收入     帝旺位: 阶段性顶峰              衰位: 行业/工作开始衰退

病位: 出现明显问题              墓位: 需要主动求变

年命/日干判断法： 判断个人事业运势走向

日干在长生：预示新发展机遇      日干在帝旺：建议保持现状并准备转型

日干在墓位：需主动寻求改变（"人挪活，树挪死"原则）

开门宫判断法： 评估行业/职业发展趋势

开门宫天干长生：新兴朝阳行业       开门宫天干帝旺：行业趋于饱和

开门宫天干病位：行业结构性问题      开门宫天干墓位：行业潜伏期（需结合星门神判断）

第四步  定性质：指用神落宫的八卦

例  1、用神天干旺落离宫为蒸蒸日上，用神天干衰落离宫为煎熬。

2、用神天干旺落艮宫为稳定发展，用神天干衰落艮宫为发展缓慢。

定趋势+定性质=精准状态描述

第五步 八门分析人事问题和表现方式

八门，属于宫内符号状态分析层面，例:

日干临开门落宫旺为积极工作工作积极性高，表现为主动投入、执行力强；

日干临开门落宫衰为工作压力大，任务推进受阻，常感力不从心。

日干临休门落宫旺为工作清闲，工作节奏适中，能游刃有余处理事务；

日干临休门落宫衰为消极，拖延任务、缺乏主动性，可能伴有贪玩懒惰。

3.日干临杜门旺：技术能力突出，工作有独特优势，能解决技术难题，形成个人工作特色；

日干临杜门衰：专业技术不足或保密意识薄弱，难以胜任专业要求高的工作，易泄露机密。

第六步 九星分析外部环境和衡量力度

双重作用：环境分析：判断个人/组织与外部环境的契合度

程度量化：作为"亮度词"衡量表现力度（如工作积极程度、薪资水平等）

天心星落宫旺衰示例

个人层面分析：

日干临天心星旺：领导力突出，具备战略思维，能统筹全局，有成为团队核心的潜力

日干临天心星衰：执行力不足，想法多但落实少，易陷入空想状态

环境适配度：

九星旺：个人能力符合社会发展需求

九星衰：专业技能已落后于时代需求

天心星开门落宫旺衰示例

开门临天心星旺：行业发展前景广阔，公司处于上升期，战略规划切实可行

开门临天心星衰：发展受阻，战略脱离实际，规划难以落地执行

环境契合度：

九星旺：行业趋势与市场环境高度契合

九星衰：商业模式与市场需求脱节

天蓬星落宫旺衰示例

日干临天蓬星旺：野心与能力匹配，制定长远规划并能逐步实施

日干临天蓬星衰：好高骛远，目标超出实际能力范围

组织层面分析：

开门临天蓬星旺：规模化发展合理

开门临天蓬星衰：盲目扩张

风险表现：资源过度分散，核心业务受损

判断要点：需结合天蓬星原始特性（冒险、扩张）与宫位状态综合判断

第七步 格局分析现状以及未来变化的方向

格局分为两个层次展现规律，天盘天干和地盘天干的自然组合反映现状，格局刻印则预示变化方向。象意解读原则：需要结合符号落宫旺衰进行精准判断，避免简单套用固定解释

例：乙加辛格局

基本象意：乙为花草之木，辛为镰刀，组合形成"割草/割韭菜"的意象

乙旺时（如落震宫）：收获多受剥削少；乙衰时（如落兑宫）：收获少受剥削多

格局刻意：乙旺：能力强者寻求更好发展平台，属主动求变；

乙衰：被迫离开当前处境，属被动变动。

判断要点：需结合具体预测事项展开联想，避免单一解读

例题：壬加庚格局

基本象意：上水（壬）下金（庚），形成"水过金属不渗透"的意象，

测事业：从事边缘性工作未触及核心，

测个人：缺乏核心竞争力，技能广而不精，

分析要点：需先解读象意，再通过格局刻印判断后续变化趋势

第八步 用神宫生克分析吉凶

例:

日干宫旺  克用神 为有能力驾驭，工作得心应手

日干宫衰 克用神 为小马拉大车非常吃力，力不从心

用神宫旺 克日干 为无法承受后果，难以承担失败风险

用神宫衰 克日于 为兵来将挡水来土掩，事件不会构成威胁。

判断依据：宫的旺衰主要参考月令，不同于单宫内部的符号能量对比

已知信息：当前有工作且产生换工作想法

核心问题：现有工作上升空间评估+换工作利弊分析

逻辑框架：先分析现有工作发展潜力，再评估工作变动后的影响

找用神： 基础用神：开门：代表当前工作岗位状态  日干：求测者自身状态（案例中为丙）

工作趋势：开门临壬（TD状态）：行业整体仍有上升空间

个人趋势：日干丙在离宫为帝旺：已达能力峰值，后续将进入衰退期

人事分析

工作状态：日干丙帝旺+临开门：保持高度工作积极性

火性上炎特征：表现为主动进取的处事方式

环境分析

行业环境：开门临天芮星（废地）：行业进入衰退期

公司发展受限：表现为市场空间收缩
