# 1. 奇门遁甲字解析

# 甲的含义：甲是天干之首，象征统帅，在十个天干中排第一位。

# 遁甲本质：指隐遁统帅甲，使其能安心运筹帷幄。核心思想是保护核心决策者。

# 三奇组成：乙奇（总参谋长）、丙奇（总警卫长）、丁奇（总后勤长），三者共同辅佐统帅甲。

# 八门作用：指人事调度系统，奇门局中包含休、生、伤、杜、景、死、惊、开八门，用于调兵遣将。

# 2. 奇门遁甲的由来

# 轩辕黄帝战蚩尤 ，涿鹿经年苦未休。偶梦天神授符诀，登坛致祭谨虔修。

# 龙龟出自河洛水，彩凤衔书碧云里。因命风后演成文，一千八十当时制。

# 太公删成七十二，逮于汉代张子房，一十八局为精艺

# 初始格局：黄帝按一年360天×12时辰=4320局创建，每时辰对应一局。

# 简化过程：风后发现每4局重复→简化为1080局（4320×1/4）

# 姜子牙按节气分候→72局（24节气×3候）

# 张良再简化→18局（72×1/4），分阳遁9局与阴遁9局

# 凶煞现象：指非常不适当的时间，做事情会出现不利现象，属于凶兆
