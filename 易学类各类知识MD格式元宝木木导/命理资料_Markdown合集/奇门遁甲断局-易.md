## 第 2 页

# 奇门遁甲断局

# 一、奇门遁甲应用概论

# 参谋功能：类似计算机辅助设计，为人生决策提供信息工具，帮助趋利避凶

# 模型特性：综合天时地利人和的预测模型，准确率约80%（类比天气预报）

# 1. 奇门断局的基本思路

# 1）急则从神

# 适用场景：处理紧急事件时无暇详细分析

# 执行方法：向值符所在方位行动（如值符在震三宫则向东移动）

# 2）缓则从门

# 优先级：门（人和）>九星/八卦（天时地利）>八神（外力）

# 理论依据："天时不如地利，地利不如人和"的古训

# 3）行动方向的四个避开

# 五不遇时：时干克日干（阳克阳、阴克阴同性）

# 时干入墓：时干代表事情，时干入墓导致事情纠结不明（如戊戌时戌为戊墓）

# 六仪击刑：地支相刑引发凶兆（如甲子戊落震三宫子卯刑）

# 庚加组合：庚金克甲木统帅，组合三奇六仪多凶应

# 4）八神的辅助作用 （北宋 烟波钓叟歌）

# 九天：宜主动出击（"九天之上好扬兵"）

# 九地：宜潜伏驻守（"九地潜藏可立营"）

# 太阴：伏兵隐蔽方位（伏兵但向太阴位）

# 六合：撤退有利方向（若适六合利逃形）

# 3. 奇门断局的注意事项

# 1）分析主要参数落宫

# 微观分析：重点观察宫内星门神仪组合（小局）

# 2）分析主要参数落宫之间关系

# 宏观分析：通过五行生克制化判断宫位关系（大局）

# 3）伏吟局主慢反吟局主快

# 速度判断：伏吟局应期较长，反吟局应期较短

# 4）内盘与外盘

# 内盘特征：阳局左盘（8341宫）、阴局右盘（9276宫），主快/近/小

# 外盘特征：阳局右盘/阴局左盘，主慢/远/大

# 4. 断应期的主要方法

# 地支变化：冲空填空、冲墓填墓时为应期

# 值使门数：根据落宫数字结合内外盘取数

# 马星触发：冲动本宫或对宫时为应期节点

# 5. 奇门的职业道德要求

# 实事求是：杜绝虚张夸大、恐吓诈财行为

# 隐私保护：有问必答、不问不答原则

# 正向引导：指导向善避恶，不可唯利是图

# 2. 奇门盘面的基本分析

# 1）标注年干月干日干时干

# 四柱关系：年干（太岁）、月干（五行旺衰）、日干（问策者）、时干（事体）

# 空亡标注：日空 时空需特别标注，预示事情不落实或有玄机

# 2）标注六仪击刑入墓

# 击刑标识：戊/己/庚/辛/壬/癸受地支相冲刑（如甲寅癸落巽四宫寅巳刑）

# 入墓影响：主事情纠结或发展受阻

# 3）标注马星

# 动态作用：可冲空解墓，每个时辰对应特定地支（如申子辰时马在寅）

# 4）标注伏吟反吟天显时格

# 伏吟局：利主利静，变化缓慢

# 反吟局：利客利动，变化快速

# 天显时格：表面纠结但最终吉利的特殊格局

# 5）标注当事人年命

# 参数选择：优先用年命而非日干，因信息量更强烈准确

## 第 3 页

# 奇门遁甲断局

# 一、测健康及断病

# 断病参数

# 1.天 芮 星  反应生病部位及严重程度

# 2.八门     反应患者抗病能力，八门吉抗病能力强

# 3.八神    反应外部环境的影响  八神吉外应吉

# 4. 天干   天芮落宫所在天干，反应人生病部位，天干旺是病的部位

# 5. 天芮落宫   落宫旺，该宫五行反应病的部位

# 治病参数

# 1.西医 天心星    天心星入宫能克天芮宫，西医能治病

# 2.中医 乙奇       乙奇能克天芮宫

# 断病步骤

# 1.断病部位:看天芮落宫 天干旺衰 天干落宫

# 2.断抗病能力:看患者年命落宫参数

# 3.断病的辅助信息:看时干

# 4.断如何治疗:看西医天心 中医乙奇

# 5.重病时断应期:看马星 看空亡填实  值使门

# 卦宫对应部位

# 巽宫对应：肝胆、经络、气管、气血系统疾病

# 离宫对应：心脏、眼部、面部疾病

# 坤宫对应：脾胃、腹部、食道、胰脏疾病

# 兑宫对应：呼吸系统、口腔、皮肤疾病

# 乾宫对应：肺、脊髓、大肠疾病

# 坎宫对应：肾脏、泌尿系统、内分泌疾病

# 艮宫对应：肠胃消化系统疾病

# 震宫对应：肝胆、淋巴、神经系统疾病

# 二、断生育

# 断病参数

# 1. 胎儿情况  癸水

# 2. 分娩情况  坤土宫

# 分娩类型判断：坤土宫参数分析

# 剖腹产信号：开门代表手术开刀

# 难产风险：白虎等凶星出现预示难产风险

# 3. 不孕育问题

# 诊断依据：需分析夫妇双方的终身局（出生年月日时构成的奇门局）

# 男方指标：精子质量：辛金；辛金临死门表示精子死亡率高

# 女方指标：卵细胞质量：癸水；癸水 入墓或临死门表示卵细胞稀少

# 孕妇：天芮星，   西医：天心星

# 三、断婚恋

# 病情部位  心部疾病  女性特有疾病

# 病情程度  八门临死门  逢未空申空

# 治疗建议  中西医结合  患者自身调理

# 患者反馈  验证结果：患有肾结石、乳腺癌，耳朵有征兆，曾患肺炎，做过五次手术。

# 六、奇门寻人

# 主要参数

# 1.走失者：年命或日干；亲戚问走失者，可用六亲关系

# 2.走失方向：开始--六合落宫；最后看年命或日干落宫（开始年命地盘，后 命天盘）

# 3.躲藏地：杜门落宫

# 4. 反吟局、逢空：反方向

# 5. 远近：内盘近、外盘远

# 6. 走失者安全：看年命、日干宫信息；看死门宫与年命宫关系；看与天蓬星关系（强盗）

# 7.难易程度：走失者 与时干同宫易回来；时干宫生走失者宫，不易回

# 走失者生时干宫，或互克，不易回

# 走失者临开休生门在外好，不易回。

# 临九天，走的较远；

# 临玄武可能被拐，腾蛇被纠緾；天蓬星强盗；丁是消息

# 伏吟难回，反吟局易回

# 8.回来时间：内盘取客小数，外盘取宫大数，结合值使门数据
