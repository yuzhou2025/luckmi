# 案4： 事业困境 缺工严重

# 第一步 先定义问题，才能解决问题

# 起奇门遁甲盘局，代表心中有疑惑难解，希望上苍指引一条明路，让我们得以看到问题症结点。但常常，盘局清清楚楚，可我们人心迷迷糊糊，无法判断何处是病处，此时更应静下心，“寻象应数，步步坐实”。

# 第二步 看当事人日干 丁 落艮宫

# 丙+丁+天英 火辣辣，艮宫“空亡”;丁于艮宫为“入墓”;杜门“门迫”。宫位病得严重。

# 直指前景受阴心急如焚。

# 第三步 看事时干 辛落乾宫

# 时干“辛”落“乾宫”。八神的“六合”为合伙，加上八门的“生门”为生意，正应了问的是“合伙生意”。而合怕冲，冲则“散”,可宫位却正逢“天冲星”!“辛+戊”也是小冲格，“辛”为“甲午辛”,  “戊”为“甲子戊”,造成子、午两者“地支冲”。 而戊“入墓”,戊为财，为本金，入了墓，代表本金亏损，或投资不理想。

# 第四步 看二宫关系

# 日干为我，落艮宫为“土”;时干为它、为工作平台，落乾宫为“金”,宫位关系为“土生金”。  “我生它”为“溲气”,代表“付出劳累，事倍功半”。且本宫病情严重，自身难保。

# 奇门盘除了事件发生过程坐实，连“时间”也都一览无遗，直指就在“今年”。流年戌在乾宫，今年合作不利 乾宫恰為戌年。

# 第五步 看引干 查事因

# 事出必有因。而“引干”查其因由，引干落于对面宫位，代表正面对着的人事物，必定有其人有其事!

# 此案引干“癸”又落“坤宫”,恰好为“日干用神对面宫位”代表问测对象直接面对的人、事或物。

# “癸入墓”,壬癸逢四害皆带有“腾蛇”,恶事缠身的意象；“己击刑”,己逢四害，可视作“不当的念头”;此时宫位内还有“玄武-偷盗之神”、“天蓬星-胆大妄为”。因此可断，问测对象犯了小人。

# 第六步 布局母法 修复法

# 1。先查家中東北方是否灯(丁入墓)不亮了，或陰暗不見天日 。 厨房瓦斯炉(丙),或廁所水管(癸+杜)堵了。室外外景也要查。 查講義符号内外景物品 ， 東北方肯定有事 。

# 依照“艮宫”宫位符号，居家布置状况一般是：  “丙”为阳火，发热处，故为“厨房”;  “癸”为“去水”,常为家中厕所。而当事人 把原厨房改成了一房间和厕所。且厕所管道堵塞。

# 第七步 布局时刻 一网打尽

# 这个盘面需要处理的宫位，除了日干本宫“艮宫”之外，一并入局的“坤宫”(事件起因)及“乾宫”(工作平台)也要一举布成，在“同个布局时间内”完成，方能引动天地之力。

# 艮宫：1摆只羊，冲丁出墓；2.摆只猴，解杜門門迫；3.摆2瓶(艮宫258数)红酒(丙+癸)。艮宫中藏有“地支丑”,利用“冲本宫”之方式，摆上地支“未”的象意物品一羊，借“丑未冲”,使丁出墓。“杜门”原宫位为“巽宫”,取巽宫所藏之支“巳”,故解局时，“杜门=巳”。利用地支六合之法，采“巳申合”,申之象意物可取”猴“。取宫位地支来定位八门属性时，“五行属土者-辰、戌、丑、未”不论。而宫位内符号没有四害又逢三奇者，可放上符合象意之物品加强其力量，艮宫内有“丙”奇，引干为“癸”,布局时最好将“符号象意”浓缩在“单一布局物”上，因此老师建议可利用“红酒”来布局，

# “乾宫”为工作平台：取地支“辰戌冲”之法，在“西北方”摆放龙(辰)将“戊”冲出墓。同时龙也为乙奇之象意之一，再次集中符号象意于一物，可谓一石二鸟。

# “坤宫”为当事人面对的处境，也为事件起因，逢“癸入墓”和“己击刑”。

# 癸入墓，利用“丑未冲”。两只牛，取坤宫宫位数“2”,十二生肖，牛为“丑”,加以布局。

# 而”己击刑“,成因在于“甲戌己”,坤宫地支为“未”,造成“戌刑未”。)而这位学员则直接以“拆法”,将西南方可能造成问题的杂物跟藤蔓植物(癸为缠绕+己为小土堆、垃圾、蜷曲纠缠物)直接清除。

# 案5：移星换斗 挽救即将破碎的婚姻  （妻子问离婚 ）

# 第一步 看盘势  返吟盘

# 九宫中任一个宫位跟他对面宫位的“天干刚好上下相反”。这就是”返吟”。

# 奇门遁甲中，返吟，是个全盘的“冲格”,冲则动。因此如其名，返吟盘代表状况反反复复-看似前进但又退回原地，反反复复，白忙一场，如同在漩涡里，挣脱不出来，可谓非常不吉。

# 第二步 看妻子日干 丙 落乾宫

# “丙”落于乾宫，丙在奇门遁甲定义中，列于三奇之中，本应是机会、希望之意义，然而丙在此宫为“入墓”,“入墓”就是困住受制，不能动，施展不开，心闷困坐愁城；“丙”五行属火，当本身状况不好时，如同火星般给人易怒、心急，容易出乱子。正应了丈夫怨念妻子脾气硬，不听劝的火爆个性了。

# “休门”,其中一个代表意义就是「婚恋家庭」-因为休门的“休”代表休闲、轻松、和谐的气氛，所以奇门以休门代表婚恋家庭之事。而休门入墓，就像婚姻走入了坟墓，婚姻关系岌岌可危，应证了当事人的苦恼。

# 更深刻的了解当事人现况，地盘天干“癸”,就是妻子面临的事情。“癸”就是天罗地网，把你层层缠绕捆绑；而宫位中，恰逢八神的”腾蛇”,也同”癸“一般，为恶事缠身之象。上述总总一串连起来，婚姻出了乱子，

# 第三步 看丈夫 丙辛合  辛落坤宫

# 宫位中的八神为“六合”。奇门中，六合代表婚恋感情的状态，坤宫恰落“空亡”之宫，“空亡”,就是空了、没了。老婆的宫位告诉我们，休门逢墓，婚姻走进坟墓了(休门+丙入墓);老公的宫位告诉我们，六合逢空，这段关系完了(六合十空亡)。

# 再仔细一看两个人用神宫位天干符号，没有一个长得一样。“没有相同天干”,主失，两人没线连着，不通气，代表两人心中所想全无交集。大大不妙啊……

# 第四步 移星换斗，挽救婚姻

# 移星换斗，就是将整个盘面转动，挪动时空，进而让本来生病的符号跑到健康的位置，以及改变宫位之间的生克关系。本案例为顺转一宫，就是所有宫位符号以顺 时针方向挪一格。转动后，妻子用神宫位换到了坎宫；丈夫用神宫位换到了兑宫，两个用神从本来宫位内入墓、空亡的病症脱身了。坎、兑两宫又为先后天卦位，“后天兑卦位为先天坎卦位”,此时可加强两宫位的关系，提高再续前缘的可能；同时，移星换斗后丈夫“兑宫”生妻子“坎宫”(兑金生坎水),也表示丈夫主动回心转意，想起妻子的好。

# 第五步 如何移星换头 布局

# 将符合两个“用神宫位内的符号特征”的物品，依照顺时针方向，择吉日吉时，在布局时间内放到“转动后”的宫位方位。

# 符合丈夫用神“坤宫”符号的物品：一对(六合)+天鹅(乙奇)+水晶(辛);放到转动后的宫位“兑宫”

# 将符合妻子用神宫位“乾宫”的物品：圆的(丙)+癸(为水，音同水晶的水)+庚  (硬的);粉水晶放到“坎宫”

# 人的意念：与当事人对谈时，一步步重燃当事人对未来的希望，使美好远景的想像越来越具体。
