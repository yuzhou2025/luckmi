# (4)临官，禄地。这个时候经历过前期的一段成长过程，现在已经有一个真正的方向了，或者说已经有事业了。那么有了事业就一定会有收入，所以在奇门中，把临官视为“禄地”也叫财位，一般只要用神在禄地，都说明此人有工作或者有收入，而禄地宫位里头的格局组合，则是代表他来财的渠道。

# (5)帝旺，羊刃。这个时候在事业上或者生活上都取得了成就，已经是一个最巅峰的时期，也是最旺的时候了。做什么事都比较顺心。但是同时，我们也要注意阳极转阴，虽然此时最旺，但是也是阴气初始的时候，所以这个时候我们就要注意了，跟乾卦中的飞龙在天一个道理，接下来就是亢龙有悔了。故而要小心谨慎，要懂得收敛退避。在奇门命局中，临了帝旺位，往往就是一个人终身成就最高的时候，我们要看一个人的终身格局，要记得看一下帝旺之地!

# 1）长生，就是事物刚刚生长的时候，长生也为旺地，处于好的一个状态，多代表这个事物才刚开始成长，刚开始去实行。初露头角但是还没有具体成型。在预测人事的时候，看一个人的家庭背景，可以去找此人命宫的长生宫位，他的长生宫位中的星门神干，就代表了他的家庭是好还是坏，家境如何。

# (10)绝地，阴极则一阳生。事物已经彻底消散，尸骨都已经不复存在了。肉体彻底从这个世界上消失，此时也是纯阴之时，然孤阴不生，独阳不长。阴极则一阳生，故有绝处逢生之意，占运势的时候，如果用神落绝地，那么就是该反转的时候了。

# (11)胎地，即怀胎。我们把十二长生比喻成人事的轮回。在经历生长到死亡之后，又重新投胎进入这个世界。在占测中，也说明这个事情正在计划或者在筹谋，人临胎地也有怀孕之意，或者是指已经在酝酿其他事情，已经有了新的想法和目标。

# (12)养，此时我们把他比作胎儿，怀孕了之后已经成形了，在妈妈体内已经有了轮廓。在占事物的时候，如果在养地，说明这个时候事物已经开始初步运作了。注意，临胎主酝酿，但是还没有实际行动，只是在心里筹划，临养则是已经开始做了。

# (2)沐浴，咸池、桃花。如果把十二长生比喻为一个人从出生到死亡的轮回最为形象。一个人经历了长生之后，就是相持的状态，古代指成⻓规范，如古代⼗五六岁举⾏的"灌带礼"。

# 沐浴是暴露的时候，也是我们最脆弱的时候，所以奇门中又把沐浴之地称为败地。不是一个吉利的状态。所以在占人的时候，临沐浴多主此人有异性缘，但是同时又不是正桃花，所以在状态上也说明此人近期运势不佳，身心容易受到伤害，办事不得力等。

# (3)冠带，万物有所规范的成⻓时期.冠带好比小孩能穿衣带帽了，事物发展小有所成。对应的年龄是青少年，古人成年多会行礼。这个状态预测事物的时候会发现徒有其表，也就是已经成型了，但是内部还是空虚，表面看起来挺好，实际没有实力。他跟离卦的象意很接近，离中虚。所以还是有些花架子的意思!

# (6)衰，形衰，阴性有形物质。好比人过中年，已经慢慢开始出现衰退的过程，此时一切都开始反转，呈现阴性的卦象，有消退的现象。运势也会由之前的成长趋势慢慢消退。但是这个时候仍然不弱，只是阴气已经初显。我们要观天之道，执天之行。懂得主客之间的进退之道，那么则无往而不利。

# (7)病，气衰，阳性机能衰退。机能出现病症、事物出现问题。而且当用神在病地的时候，说明一个事物已经出现了毛病，占事业，工作出现了毛病。占疾病，身体出现问题。

# (8)死，形灭。好比人已经去世了，但并不是真正死亡。说明一个事物已经走到头了，没有在向上发展的空间了，事业遇瓶颈了、不发展了。

# (9)墓者，阴阳剥离称"空亡"，⾮虚⽆⽽是有形世界状态。事多昏晦，人多运势受阻。已经入土为安了。凡入墓，必须要冲墓才吉。不管是占人还是事物，只要入墓，都没有生气，缺乏活跃性，死气沉沉的。所以在奇门遁甲中，一般在占应期，有关时间的问题，如果用神入墓，多以冲墓为期。
