## 一、三奇贵人格

三奇贵人格是命格中最好的格局之一。

> 三奇贵人是指「天奇、地奇、人奇」三者同时出现。这种命格在八字中很少见，物以稀为贵。三奇命人绝对不是一般人。

**三种三奇：**

| 类型 | 组成 |
|------|------|
| 天上三奇 | 乙·丙·丁 |
| 地上三奇 | 甲·戊·庚 |
| 人间三奇 | 辛·壬·癸（甲·壬·癸） |

四柱中这三类天干同时出现，即为「三奇贵人格」。

> 古书记载：**三奇拱向紫微宫，最喜人生命里逢；命里阴阳真宰相，功名富贵不雷同。**

### 三奇贵人格注意事项

1. 顺序可以颠倒，**顺序打乱则贵气受损**。
2. **地上三奇「甲戊庚」格局最高**，必是国家栋梁。
3. 三奇需要有地支「合」（六合、三会、三合）来助贵气。
4. 天干三奇成格，若地支遇到「刑冲破害」，贵气受损。

> 一生抱负极大，胸怀天下，有宰相之才。

## 二、天元一气格

> **四柱天干一样，地支不一样。**

天元一气格的八字总共有 **10 组**，此命为奇格，很少见到，但八字五行缺少 2–3 个。

**口诀（天元一气）：**

> 四子贫寒多短寿，四午富足下有害；四丑人孤刑，四寅人忠良；
> 四卯仁德多富豪，四申好动路上亡；四庚他乡走，四辛寿限长；
> 四巳清静有余钱，四丁寿不长；四卯贫苦而有寿，四酉仗义多伤残；
> 四子定富足，四午人夭亡；四辰甲日多大富，四戌见戌有刑伤。

**天元一气格 10 组（举例）：**

| 四柱 | 说明 |
|------|------|
| 壬寅 壬寅 壬寅 壬寅 | —— |
| 庚辰 庚辰 庚辰 庚辰 | —— |
| 乙亥 乙酉 乙酉 乙酉 | 成吉思汗的八字（乙亥 乙酉 乙酉 乙酉） |
| 乙酉 乙酉 乙酉 乙酉 | 隋炀帝的八字 |
| 丙申 丙申 丙申 丙申 | —— |

> 人之八字，最宜四柱流通、五行生化；天元一气格四柱缺陷，五行偏枯。虽然富足，但孤傲而且短寿。
> 如隋炀帝（乙酉四柱）：在位施暴政，最后五十岁时死于兵变——富贵而结局凄惨。

## 三、禄元互换格

> 禄元互换有四天，生时必要透正官；大破后成你宝盆，实离乡富由天。

年柱成大事、大富大贵的格局。**中年以后可以生出无数的正官正财，是非常好的格局。**

**典型组合：**

- 戊申日见乙卯时
- 丁酉日见壬寅时
- 丙子日见癸巳时
- 庚寅生时甲申换
- 庚子日见丁巳时

> 原来戊午见丁巳，庚寅生时甲申换。
> 身旺财官为喜用时，互换禄元，富贵双全。

## 四、杀印相生格

> 杀生印，印生身，富贵双全；杀不离印，印不离杀，杀印相生，功名显达。

**杀印相生格需要的条件：**

1. **日元必须弱**（身弱）。
2. 本命局有**七杀**、有**正印**。
3. 印与杀的比例要**成正比**。
4. 日元邀请食神制七杀时，本命局**不能见到偏印**（否则为普通格局）。
5. **男命（乾造）需要阴日干，女命（坤造）需要阳日干**（有利）。
6. 大运流年遇到偏印克制食神 → 破格。
7. 本命局**不要有刑冲破害**，否则贵气减少。

> 杀印相生格文武兼备，功勋赫然，出将入相。
> 日元弱、七杀多，需要印枭来化杀，把七杀为己所用，这叫做「杀印相生格」。

## 五、食神制杀格

> 食神制杀格的条件：**身强，杀旺，食神旺**，才能成格。此为贵格，十有九贵，属中上等格局。

**核心要点：**

1. **必须身强**——食神制杀格的前提是日主要身强。身强方能「借食为福，制杀为权，担财为富」。若身弱，食伤官杀为忌凶，会出现官非不断、伤残牢狱，贫贱之命。
2. 七杀为**四凶神之首**，代表病痛、执法单位、小人等不好的信息，见到了一定要制服。
3. 食神是**吉神**，为财根，可以带来财富；在命局中可以制住七杀，使其不能伤害到命主本身，所以叫做「食神制杀格」。
4. 注意七杀与食神的比例，**平衡最好**：
   - 杀多食少 → 喜比劫生扶食神，或遇食伤大运流年可发达；
   - 杀少食多 → 七杀被制伏太过，喜财星生扶七杀，遇官杀大运流年名利双全。
5. 日元地支**需要有根**（微根都行），无根易短寿。
6. 食神**不能被合化、被冲**，否则七杀无制必应灾。
7. 多柱都有正印最好；年柱正印（青少年无忧、晚年有灾），时柱正印（晚年无忧、青少年有灾）。

> 食神制服了七杀，使命格变好：从一个暴力的人变成认真讲诚信、很有能力的人。食神又生财，为食神制杀格——当官有钱，为富贵之命。
> 韩信、黄兴、美国总统奥巴马都是食神制杀格。

**应灾情形（七杀无制）：**

- 命主身弱，天干大运流年同时出现七杀，与流月七杀形成「三杀相会」→ 易死亡。
- 身强用食伤克制七杀，整个命盘没有食神伤官 → 杀无制易出灾祸。
- 逢大运克泄耗过多，日元从身强变身弱 → 七杀无制易出灾祸。
- 财克印、偏印夺食 → 七杀无制。

## 六、身杀两停格

> 在所有成格之七杀格局中，尤为上上等富贵者，当属「身杀两停格」。入格者，定为人中龙凤，富贵双全，风云会际人物。

**身杀两停格的条件：**

1. **日元与七杀的能量差不多**（大致均衡）。
2. 日元遇到大运流年克泄耗过多变为身弱时，七杀无制易出灾祸。

**喜忌（大运流年）：**

| 本命局状态 | 大运流年喜见 | 说明 |
|-----------|------------|------|
| 七杀能量大、日元身弱 | 正印化杀 | 变为「杀印相生格」 |
| 日元能量大、七杀弱 | 食神 | 变为「食神制杀格」 |
| 日元与七杀能量均衡 | —— | 平衡态，最吉 |

> 日元太弱担不了财，日元太强容易狂妄自大、不听劝告、盲目扩张，反而容易损财、伤残牢狱之灾。
> 相反，日元去生财则比较容易发财。

## 七、伤官配印格

> 伤官配印格容易成名（成龙、徐静蕾、陈好、周恩来总理都是此格局）。

**没有一个成大事的八字全部为吉神——所有伟人的八字中一定有伤官或七杀，两者都是恶神。如果八字组合得当，恶神被制住，命主才能成就大事。**

**伤官配印格的条件：**

1. **日元身弱**，伤官为忌凶，**印为喜用**，以印制伤，才能成格。
2. 伤官配印格，最忌见财星——大运流年财星坏印，伤官无制，易出口舌官司。
3. 伤官与印的**距离要得当**，离得太远则印制不住伤。
4. 日元有根，不能太弱，否则短寿。
5. 本命局**不要有刑冲破害**，否则贵气减少。

**性格：**

- **坏的一面**：狂妄自大，认为老子天下第一，谁也不服；不服管教，一身傲骨，自视不凡，恃才傲物，心高气傲，锋芒毕露。
- **好的一面**：积极开拓，上进心强，争强好胜，聪明伶俐，企图心强，越挫越勇。

> 伤官重则为自己有血光之灾，代表官司口舌纷争。命局正印被克，伤官无制，这一年命主容易与人发生口舌、官司。

## 八、伤官生财格

> 聪明不过伤官，伶俐不过七杀。
> 八字日元身强，伤官旺，财旺，必是富贵之人。

**伤官生财格的条件：**

1. **日元身强**，伤官为喜用，财才为喜用 → 以伤生财才，泄掉伤官恶神之气，方能成格。
2. 日元身强，伤官旺，**八字无财才** → 虽然聪明伶俐，但必然贫穷（大运流年遇财也会有发财机会）。
3. 日元身强财旺，但五行缺木无食伤 → 大运流年遇食伤也会发财。

**伤官生财格最忌：**

> 伤官见官为祸百端——伤官狂傲不服管教，以为自己天下第一；有官来管自己时，容易惹事。

## 九、伤官见官格

> 伤官见官，祸事百端。**此格局为凶格，只做介绍，不建议采用。**

**含义：**

- 伤官代表好胜逞强、不服管制、自命不凡，对谁都看不上眼，高傲清高。
- 官代表上级部门、国家法律法规，是对个人的一种限制行为。

**伤官见官格的条件：**

1. **日元身强，官为喜用**，此时伤官见官 → 以凶论，容易出灾祸。
2. 日元身弱，本命局伤官、正官旺，两忌凶互相制约，为日元减轻压力 → **不以凶论**。
3. 伤官见杀，不以「伤官见官」论。
4. 日元身强，本命局伤官旺，**不见正官** → 为「伤官伤尽」，即使大运流年遇正官星，也不会出现灾祸。

> 日元身强，本命局伤官较旺但不见正官 = 伤官伤尽。四柱伤官伤尽，岁运遇官星反吉利。
> 日元身弱、伤官正官旺，两忌凶互相制约 → 伤官见官不以凶论。

**应灾表现：** 丢职、受领导批评、工作受制、下岗，或官灾诉讼；女同志与丈夫不和等。

> 所谓「伤官见官祸事百端」，是指原四柱八字中伤官不尽，岁运又遇官。日元身强、时干有正官 → 命主在晚年易出灾祸（两个喜用互相克制）。

## 十、枭神夺食格

> 枭神夺食，确实是灾星的标志。七杀生枭神，枭神遇到食神 → 应灾大；财多克枭神，枭神遇到食神 → 应灾小。

**基本概念：**

- **偏印**称为「枭神」，专门与食神对着干。
- **食神**为福气、为财根。原命局出现枭神夺食，命主走到食神运的年龄，必然出现不开心的事情，重者出现伤病、牢狱、车祸之灾。

### 枭神夺食简单分两种情况

| 情形 | 应灾大小 |
|------|---------|
| **命局自带枭神夺食** | 应灾大 |
| **流年成局**（本命局只有枭神或食神，在流年/大运中凑齐） | 应灾相对较小 |

**判断轻重的关键：**

1. **透干/本气 vs 地支藏干**：枭神与食神都在天干透出 → 应灾大；枭神透干或地支本气、食神为地支藏干 → 应灾大；隔位力量变小，紧邻力量变大。
2. **数量**：多个枭神夺一个食神 → 应灾大；一个枭神夺多个食神 → 应灾小。
3. **喜忌**：日元身强，食神为喜用、枭神为忌凶时 → 应灾大；日元身弱，食神为忌凶、枭神为喜用时 → 应灾小。
4. **位置**：
   - 月令枭神夺时干/时支食神 → 应灾小；
   - 月令枭神夺年干/年支/月干/日支食神 → 应灾大；
   - 年干/月干枭神夺食 → 应灾大。

> 例：月令枭神夺周围年干/年支/月干/日支食神 → 应灾大；月令枭神夺时支/时干食神 → 应灾小。
> 例：多个偏印夺一个食神，命主走到月干宫位二十多岁时得过乳腺癌。

### 枭神夺食的五行类化

> 再从枭神所夺的五行进行类化（看枭神与食神的五行属性）：

| 枭夺食的五行 | 应灾部位 |
|-------------|---------|
| 枭金夺木 | 木主人身、类象为肢体、手脚、头部等，可能在这些部位受伤 |
| 枭木夺土 | 脾胃、皮肤、肌肉等 |
| 枭土夺水 | 肾病、血液 |
| 枭水夺火 | 心脏、眼睛、烧伤 |
| 枭火夺金 | 刀伤、骨折 |

> 应灾就会较大，而这些宫位所代表的六亲也会出现不和、不睦的现象。

**大运推断示例：**

> 本命局没有枭神夺食，走到辛金大运时遇枭神，可判断命主在该大运非常不开心——代表心爱的东西被抢走，或升职的机会被夺走，严重的甚至出现抑郁、自杀等行为。
> 枭神能量加强 → 应灾大；枭神能量减少（财克枭神） → 应灾小。

## 十一、一气专旺格

> 一气专旺格是指本命局比劫、印枭非常多，气偏旺于一方；或者地支有三会或三合成日主同一五行（即旺气专一集中在日主上）。

### 一气专旺格共有五种

| 名称 | 五行 | 特点 |
|------|------|------|
| **曲直格** | 木气专旺 | 仁慈、正直、公平，能克服困难；木气纯粹，身材较魁梧高大 |
| **炎上格** | 火气专旺 | 对人热情、讲礼，但火太烈，性格急躁、偏激、感情用事 |
| **稼穑格** | 土气专旺 | 十分诚信，讲孝道，做事稳重 |
| **从革格** | 金气专旺 | 性格刚强、有骨气，但难免专横武断；多有创新异特思想，仗义轻财，敢怒敢言，声音洪亮 |
| **润下格** | 水气专旺 | 心性聪慧，应变力强，办法多，善于以智取胜、以柔克刚；缺点是后力不能持久 |

**一气专旺格的特点：**

1. 由于五行气势皆归旺于日主，为人大多精力充沛、自尊心强、有骨气、有潜在的领导才华，容易居于领导者地位，自信心强、干劲足。
2. 人生容易**大起大落**——好的时候很好，差的时候也很差，两个极端。
3. 有些是地支三会或三合，合化出与日元相同的能量（并非从弱格）。
4. **缺点**：因五行不全，往往六亲、性格、身体、运程有所缺陷。

> 润下格：整个命局里只有水和木两种五行，水生木，木气非常旺盛 → 属水气专旺。
> 稼穑格：满盘皆为土，火生土，土的能量非常强。
> 从革格：乙庚合金，乙木合化成辛金，土生金 → 属金气专旺。
> 炎上格：巳午未三会火，木生火 → 属火气专旺。

**大运喜忌（一气专旺）：**

- 喜：遇到印枭比劫，本身有两个庚走到大运流年又遇庚，或遇食伤、财才 → 能有奇特际遇与成就。
- 忌：从强日元为弱时，**最忌行官杀大运流年**，谨防灾祸。

## 十三、日贵格

> 日贵格总共有六组（丁酉、丁亥、癸巳、癸卯、庚寅、庚午），按六十甲子阳干配阳支、阴干配阴支排列：

**日贵格六日：**

> 甲戌（戊）兼牛羊，丙丁猪鸡位；壬癸兔蛇藏，庚辛逢虎马——此是贵人方。
> 乙己鼠猴乡……

即：**丁酉、丁亥、癸巳、癸卯、庚寅、庚午**（符合「日干坐贵人」）。

> 日贵格出过很多皇帝、大人物。这个格局出过很多皇帝。
> 即使本命局日柱不是日贵，但后天大运走到「丁酉日」天干地支 → 也会升官发财。
> 日贵格为人有慈悲心、讲义气、有道德。若是女性，则一定是长得漂亮。

## 十四、天地合

> 天地合：天干地支都有六合的关系，而且天干地支合化出来相同的气，并互相引化。此格最为尊贵，多是大富大贵之人。

**要点：**

- 天干有合、地支也有合，合化出相同的气 → 最尊贵。
- **合去忌凶之神为吉**（表示坏事情被拖后）；**合去喜用之神为凶**（表示好事情被牵制、拖延，有好事儿就是得不到）。
- 遇到大运流年与本命局出现「干支天地合」，也要分析吉凶以及宫位六亲应灾。

> 例：地支寅亥合，偏印代表技术，比肩为朋友 → 可知他社会上的朋友搞技术的、或艺术家能为其提供帮助（断命主的父亲或社会上的哥哥姐姐在工作上对他有帮助）。

**天地合出现的宫位：**

- 出现在**年月两柱** → 主少年家境富有；
- 出现在**月日两柱** → 青年、中年时期富有；
- 出现在**日时两柱** → 主中晚年安康，寿命长。

> 普通人遇到大运流年天地合，也会有好事发生。天地合贵气不如「天地合又合化」纯。

**天地合举例（五行合化）：**

- 甲己合土、乙庚合金、丙辛合水、丁壬合木、戊癸合火；
- 地支：寅亥合木、卯戌合火、辰酉合金、巳申合水、午未合土。

> 满盘都是印枭比劫生助日元 → 属「天地合」的变体（如从革格：乙庚合金、土生金）。
