# 弘扬·传承 命理格局 —— 辰戌丑未为墓库

> 主题：**辰戌丑未为墓库，既是库又是墓**

## 一、总纲：库与墓

- **辰、戌、丑、未** 为地支 **四墓库**，五行分属：辰（阳土）、戌（阳土）、丑（阴土）、未（阴土），统称 **土行四库**。
- 核心口诀：

> **库为仓库，墓为坟墓。**

| 状态 | 含义 | 吉凶取向 |
|------|------|----------|
| **库** | 收藏、储存之所（财库、官库、印库……） | 宜 **开库** —— 库开则得财、得官、得势 |
| **墓** | 收敛、埋葬之所 | 宜 **闭墓** —— 墓开则破财、损身、失势 |

- 判断是「库」还是「墓」，关键看 **该五行的能量是否达到 40 分以上**：
  - 能量 **≥ 40 分** → 为 **库**（辰戌丑未藏风聚气，可催财入库）
  - 能量 **< 40 分** → 为 **墓**（打开则破财、损身）

## 二、四墓库分论

### 1. 辰 —— 水库（阳土 · 东南）

- 五行属性：**阳土**，方位东南。
- 所藏：**癸水（主气）**、乙木、戊土。
- 类象：水库、湿土、水库聚集之所。
- 对应：
  - 天干入墓：**辛、壬** 入辰墓
  - 身体：**肾脏、泌尿系统、内分泌**
- 开库要点：辰为 **水库**，开辰库多与水、财相关。

### 2. 戌 —— 火库（阳土 · 西北）

- 五行属性：**阳土**，方位西北。
- 所藏：**丁火（主气）**、戊土、辛金。
- 类象：火库、燥土、炉冶之所。
- 对应：
  - 天干入墓：**乙、丙、戊** 入戌墓
  - 身体：**心脏、血脉、小肠**
- 开库要点：戌为 **火库**，开戌库多与火、官、名相关。

### 3. 丑 —— 金库（阴土 · 东北）

- 五行属性：**阴土**，方位东北。
- 所藏：**己土（主气）**、癸水、辛金。
- 类象：金库、寒土、矿藏之所。
- 对应：
  - 天干入墓：**丁、己、庚** 入丑墓
  - 身体：**肺、大肠、骨骼**
- 开库要点：丑为 **金库**，开丑库多与金、财、义气相关。

### 4. 未 —— 木库（阴土 · 西南）

- 五行属性：**阴土**，方位西南。
- 所藏：**己土（主气）**、丁火、乙木。
- 类象：木库、热土、园林之所。
- 对应：
  - 天干入墓：**甲（乙代）、癸** 入未墓
  - 身体：**脾胃、腹部、肌肉**
- 开库要点：未为 **木库**，开未库多与木、文、生发相关。

| 墓库类型 | 对应地支 | 所藏主气 | 象义 |
|----------|----------|----------|------|
| **比劫墓库** | 辰 / 戌 / 丑 / 未 | 视具体格局 | 兄弟姐妹、同辈、竞争者之归宿 |
| **食神墓库** | 辰 / 戌 / 丑 / 未 | 视具体格局 | 食伤（才华、子女、技艺）之归宿 |
| **财星墓库** | 辰 / 戌 / 丑 / 未 | 视具体格局 | **财库** —— 最重要，主财富积蓄 |
| **官杀墓库** | 辰 / 戌 / 丑 / 未 | 视具体格局 | 官位、名望、权柄之归宿 |

## 四、开库与闭库的法则

### 1. 何时宜开库

- 命主 **身强**，所藏五行为 **喜用神** → 宜开库，开则得用。
- 例：身强财旺、食伤旺，开 **财库（辰/戌/丑/未之财库）** → 催财入库。

### 2. 何时宜闭墓

- 命主 **身弱**，所藏五行为 **忌凶神** → 宜闭墓，开则招灾。
- 例：身弱财多，墓开则 **破财、被财所累**。

### 3. 开库的常用方法

| 方法 | 原理 |
|------|------|
| **冲** | 辰戌相冲、丑未相冲 —— 用相冲之地支冲动墓库（如用戌冲辰开水库） |
| **刑** | 丑未戌三刑 —— 三库相见，土旺极而自开 |
| **合** | 子丑合、午未合、辰酉合、卯戌合 —— 合化引动墓库 |
| **天干引化** | 天干透出所藏五行（如辰库见壬癸水透出），能量放大数倍 |

## 五、大运流年遇墓库的吉凶判断

- **岁运逢墓库**，先看该墓库所藏五行为何、是喜是忌：

| 情况 | 断语 |
|------|------|
| 喜用入库（库开） | 得财、得官、得机遇，多有喜庆 |
| 忌凶入库（墓闭） | 收敛、沉寂，反为平安 |
| 喜用入墓（墓开） | 吉气化无，好事难成 |
| 忌凶入墓又逢冲 | 凶神放出，易有灾祸 |

- 口诀：

> **库宜开，墓宜闭；喜宜动，忌宜静。**

- 特别提示：**辰戌丑未四库全**（四墓库齐备于四柱 / 大运），多主 **喜收藏、聚财、守成**，但也易有 **固执、郁结** 之性。

## 六、核心要点小结

1. **辰戌丑未** = 水火金木四墓库，本质为土。
2. **能量 ≥ 40 分为库，< 40 分为墓**；库开则吉、墓开则凶。
3. 判断前提：**先辨日元身强身弱、所藏五行的喜忌**。
4. 开库手段：冲、刑、合、天干引化。
5. 大运流年逢墓库，**喜忌定吉凶，开闭定得失**。
